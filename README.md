# Aurora - Part_5_Backend_Admin_and_Shared

This folder contains the files assigned to one team member for GitHub contribution tracking.

## Important
- Copy/merge these files into the main Aurora repository; do NOT create 5 separate production repositories.
- Part 1 owns the shared frontend images/assets.
- Part 5 owns shared backend infrastructure (`server.js`, DB config, package files, auth/user/event backend).
- Do not commit `backend/.env` or secrets.
- Recommended commit message: `feat(part-5): <your feature>`
